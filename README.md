# Weitao Wang — Personal Website Starter

A warm, nature-inspired Quarto personal website with Home, About, Projects, Publications, Life and CV.

## First run

1. Install Quarto: https://quarto.org/docs/get-started/
2. Install Visual Studio Code: https://code.visualstudio.com/
3. Unzip this folder and open `weitao-personal-website` in VS Code.
4. Open Terminal → New Terminal.
5. Run `quarto preview`.

The browser will open a local website. Press Ctrl+C in the terminal to stop preview.

## Updating content

- Home: `index.qmd`
- About: `about.qmd`
- Projects: `projects/index.qmd`
- Publications: `publications.qmd`
- Life: `life/index.qmd`
- CV: `cv.qmd`
- Menu/site configuration: `_quarto.yml`
- Colors/layout: `styles.css`

These are draft pages. No personal photos, publication citations or contact details are published in this starter.

## Later deployment

See https://quarto.org/docs/publishing/github-pages.html. Don't deploy until you've reviewed the information you want to make public.
